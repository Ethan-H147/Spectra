# Privacy policy

Spectra processes imported audio on the user's computer. The application does not collect telemetry, create user accounts, or transmit audio, filenames, analysis results, diagnostics, or usage data.

## Local data

Spectra stores these preferences through the operating system's application-settings service:

- text scale;
- processing-performance mode; and
- the whole-file model memory limit.

Spectra keeps imported audio and generated analysis data in memory while the application runs. It writes audio or PDF output only after the user chooses an export location. Spectra does not retain reconstruction caches after exit.

## Network access

Spectra does not make network requests. Links to the project repository, releases, policies, and issue tracker open in the user's default browser. The browser and destination website apply their own privacy policies.

## Removing local data

Uninstalling Spectra removes application files installed by the Spectra installer. Windows can retain the three preferences listed above in the current user's application settings. These preferences contain no audio, filenames, or file paths.

## Changes

Any future feature that transfers data will require an update to this policy before release. The feature will identify the transferred data, destination, purpose, and user control.

Questions about this policy can be filed in the [Spectra issue tracker](https://github.com/Ethan-H147/Spectra/issues).
